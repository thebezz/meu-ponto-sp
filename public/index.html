        Como usar

        1. Busque o seu ponto pelo nome da rua.
        2. Veja em quantos minutos cada ônibus chega. O painel se atualiza sozinho.
        3. Toque em uma linha para ver os ônibus dela no mapa, ao vivo.
        4. Toque em 🔔 para ser avisado quando o ônibus estiver a 5 minutos.
        Dados de transporte: SPTrans — API Olho Vivo. Previsões são estimativas da SPTrans e podem variar. Mapa © OpenStreetMap.
